# CSCI160-CH07EXS
Programming Examples From Java Illuminated Book by Anderson and Franceschi
## Examples 01 and 02
- Auto01.java - The first Auto Class  
- AutoClient01.java - The first Auto Client
## Examples 03 and 04  
- Auto02.java - The second Auto Class adds accessor statements to return information about the car.
- AutoClient02.java - The second Auto Client prints these new values  
## Examples 05 and 06  
- Auto03.java - The third Auto Class adds mutator methods so information about the car can be updated.
- AutoClient03.java - The third Auto Client updates values (sometimes unsuccessfully) and prints the new info.  
## Examples 07 and 08  
- Auto04.java - The fourth Auto Class provides the method to calculate mileage for an auto object.
- AutoClient04.java - The fourth Auto Client implements this method.  
## Examples 10 and 11  
- Auto05.java - The fifth Auto Class can calculate miles per gallon for an auto object.
- AutoClient05.java - The fifth Auto Client implements this methods.  
## Examples 12 and 13  
- Auto06.java - The sixth Auto Class makes use of the toString and equals method.
- AutoClient06.java - The sixth Auto Client implements these methods.  
## Examples 14 and 15  
- Auto07.java - The seventh Auto Class makes use of the getCountAutos class to determine how many Autos have been instantiated.
- AutoClient07.java - The seventh Auto Client implements this method.  
## Examples 16, 17 and 18  
- Algebra.java - Returns the greatest common denominator of two numbers.
- Rational.java - Performs operations on fractions.
- RationalClient.java - Implements all of the methods in Algebra.java and Rational.java.  
## Example 21  
- How to use an enum to simplify using days of the week in a program.  
## Example 22  
- Using enums for days of the week to print daily specials for a restaurant.
